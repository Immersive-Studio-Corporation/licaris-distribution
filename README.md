# Licaris

Dépôt public de distribution du launcher et du modpack Licaris, géré par Immersive Studio.

Les versions publiées seront disponibles dans [Releases](https://github.com/Immersive-Studio-Corporation/licaris-distribution/releases).

- **Setup Windows** : installation du launcher et mises à jour automatiques des prochaines versions.
- **Portable Windows** : exécutable à remplacer manuellement lors des mises à jour du launcher.
- **Modpack** : fichiers synchronisés par le launcher avant de jouer.

Les sources du projet sont conservées dans un dépôt privé séparé. Ce dépôt héberge les fichiers destinés aux joueurs.
